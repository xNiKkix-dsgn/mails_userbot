# Telethon userbot для рассылки постов

Этот проект — userbot на базе **Telethon**, который берёт пост из канала и пересылает его в список чатов, заданный в отдельной группе. Пересылка сохраняет форматирование, премиум-эмодзи и медиа (изображения, альбомы), так как используется forward от аккаунта пользователя.

## Быстрый старт

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

3. Запустите рассылку:

```bash
python userbot.py \
  --source-channel "@source_channel" \
  --targets-group "@targets_group"
```

## Как работает

- Скрипт берёт **последний пост** из указанного канала (или фиксированный `SOURCE_MESSAGE_ID`).
- В группе со списком чатов ищется **последнее сообщение**, где перечислены получатели (по одному на строку или через пробел/запятую).
- Пост пересылается во все чаты.
- Между циклами — случайная пауза от 10 до 20 минут (по умолчанию), чтобы избежать спама.

## Переменные окружения

- `API_ID` — ваш API ID из [my.telegram.org](https://my.telegram.org).
- `API_HASH` — ваш API HASH.
- `SESSION_NAME` — имя сессии Telethon (по умолчанию `userbot`).
- `SOURCE_CHANNEL` — канал-источник (username, id или ссылка).
- `SOURCE_MESSAGE_ID` — ID конкретного сообщения в канале (опционально).
- `TARGETS_GROUP` — группа, где хранится список чатов.
- `TARGETS_MESSAGE_ID` — ID сообщения в группе со списком чатов (опционально).
- `SEND_DELAY` — пауза между пересылками в чаты (сек), по умолчанию `1.0`.
- `INTERVAL_MIN` — минимальная пауза между циклами (сек), по умолчанию `600`.
- `INTERVAL_MAX` — максимальная пауза между циклами (сек), по умолчанию `1200`.
- `STATE_FILE` — файл состояния с последним отправленным ID (по умолчанию `.state.json`).

## Формат списка чатов

В группе можно указать:

- `@some_channel` или `some_channel`
- `-1001234567890` или `123456789`
- `https://t.me/some_channel`

Скрипт берёт **первое найденное сообщение**, в котором есть такие идентификаторы.

## Важные замечания

- Telethon работает с **аккаунтом пользователя**, поэтому при первом запуске потребуется ввести код подтверждения.
- Соблюдайте правила Telegram, чтобы избежать ограничений за массовые рассылки.

## Пример

```bash
export API_ID=123456
export API_HASH=abcdef1234567890abcdef1234567890
export SOURCE_CHANNEL=@source_channel
export TARGETS_GROUP=@targets_group
python userbot.py
```
